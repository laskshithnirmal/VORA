# VORA - Modern E-Commerce SPA

VORA is a data-driven Single Page Application (SPA) built using **Vue 3**, **TypeScript**, and **Tailwind CSS**. It consumes the **DummyJSON API** to provide a seamless shopping experience.

## Features
- **Product Catalog**: Fetch and display products with category filtering.
- **Search**: Real-time search functionality.
- **Authentication**: Login and Register simulation with JWT storage.
- **Shopping Cart**: Global state management with Pinia to manage cart items.
- **Dark Mode**: Fully supported light/dark theme toggle.
- **Responsive Design**: Optimized for Mobile, Tablet, and Desktop.

## Prerequisites
Ensure you have **Node.js** (v18 or higher) installed on your machine.

## Installation & Setup

1. **Extract the ZIP file** and open the folder in your terminal.
2. **Install dependencies**:
   ```bash
   npm install
3. **Run the development server**: npm run dev
4. Open your browser and navigate to **http://localhost:5173**

# Tech Stack
1- Framework: Vue 3 (Composition API)

2- Language: TypeScript

3- State Management: Pinia

4- Routing: Vue Router

5- Styling: Tailwind CSS

6- API: DummyJSON
